# VAROLUŞSAL DÖNGÜ MAKİNESİ

## Bu yazılım neden var?

Çünkü insanlık binlerce yıldır "Neden buradayız?" diye soruyor ve hiçbir cevap alamıyor. Biz de dedik ki: "O zaman cevap gelene kadar dönelim."

Bu program, evrenin en derin sorularını çözmek için tasarlanmış, dünyanın ilk ve tek **sonsuz döngü tabanlı felsefi işletim sistemi**dir. Gerçekten çalışır. Gerçekten döner. Gerçekten hiçbir şey yapmaz.

### Nasıl çalışır?

1. Programı çalıştırırsın.
2. Program derin felsefi sorular sorar.
3. Program kendine cevap vermeye çalışır.
4. Program başarısız olur.
5. Program 1. adıma döner.
6. Sen çay demlersin.

### Kurulum

```bash
git clone https://github.com/Tentivory/varolussal-dongu-makinesi.git
cd varolussal-dongu-makinesi
python3 dongu.py
```

**Uyarı:** Bu programı çalıştırdıktan sonra anlam aramak üzere yola çıkabilirsiniz. Sorumluluk kabul etmiyoruz.

### Özellikler

- %100 gerçek sonsuz döngü
- Rastgele varoluşsal kriz üretimi
- CPU'yu yormadan ruhunuzu yorar
- Çıkış yok, çünkü çıkış da bir illüzyon

### Lisans

Bu yazılım "ne istersen yap ama bize sorma" lisansı altındadır.
